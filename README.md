# NO CHILL — แอปหายใจสาย Anti-Mindfulness

สูดความโมโห แล้วระบายเป็นแรงปา · ย่อยความในใจ · กดรัวแป้น · โดนโค้ชปากจัดแซะ — ใช้ได้ทั้งคอมและมือถือ (ติดตั้งเป็นแอปได้)

Next.js 16 + React 19 + Motion — ภาพทั้งหมดวาดด้วย Canvas 2D และ SVG, เสียงสังเคราะห์ด้วย Web Audio ไม่มีไฟล์รูปหรือไฟล์เสียงเลย

Backend อยู่ที่ [NOCHILL_BE](https://github.com/kwank6704/NOCHILL_BE)

## รัน (ต้องใช้ Node ≥ 22.13)

```bash
npm install
npm run dev   # http://localhost:3000
```

frontend proxy `/api/*` ไปที่ backend ตาม env `API_URL` (ค่าเริ่มต้น `http://localhost:4000`) — ถ้าไม่มี backend แอปยังเล่นได้ แค่ไม่บันทึกสถิติ

## ฟีเจอร์

| หน้า | ทำอะไร |
|---|---|
| `/rage` | กดค้าง (หรือ Space) = สูดความโมโห ลูกโป่งพองและสั่น ความดันพุ่ง → ปล่อยแล้ว **แตะค้าง ลาก เหวี่ยง** ของใส่กำแพง ของแตกเป็นชิ้นจริงจาก sprite, กำแพงร้าว, เศษกองบนพื้น |
| `/shredder` | พิมพ์สิ่งที่เซ็ง → กดค้างดูดเข้าเครื่อง (ยิ่งนานยิ่งละเอียด: เส้น → ไขว้ → ผง) → ปล่อยให้ย่อยแล้วปลิวไปกับลม |
| `/mash` | รัวปุ่มอะไรก็ได้ หรือแตะรัวจอหลายนิ้ว คีย์บอร์ดร้อนขึ้น ปุ่มหลุดกระเด็น ร้อนถึง 100° ค้างไว้ = ระเบิด จบรอบแล้วแอป "แปล" สิ่งที่รัวให้ |
| โค้ช (ทุกหน้า) | แซะเมื่อหายใจสั้น / กลั้นนาน / กดรัว / นั่งนิ่ง / ย่อยข้อความว่าง |
| `/stats` | KPI, กราฟรายวัน, การกระจายความดัน, ของที่พัง, หอความอับอาย, กำแพงความเซ็ง |

## โครงสร้าง

```
src/app/            หน้าเว็บ, manifest และไอคอน PWA (วาดด้วยโค้ด)
src/components/     React components (Nav, Coach, HoldButton, …)
src/lib/rage/       เอนจินปาของ + ลูกโป่ง
src/lib/shredder/   เอนจินเครื่องย่อย
src/lib/mash/       เอนจินกดรัว
src/lib/items.ts    ของที่ปาได้ (วาดด้วย Canvas)
src/lib/shatter.ts  ตัดภาพเป็นชิ้นแตก
src/lib/audio.ts    สังเคราะห์เสียงทุกเสียง
```

## มือถือ

เป็น PWA — แถบเมนูล่าง, ไอคอน, เปิดเต็มจอเมื่อติดตั้ง (ต้องเสิร์ฟผ่าน HTTPS) · Android มีปุ่มติดตั้ง, iPhone: แชร์ → เพิ่มไปยังหน้าจอโฮม · การสั่นใช้ได้บน Android เท่านั้น
